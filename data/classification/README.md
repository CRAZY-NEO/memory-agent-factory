# 个人记忆分类固定评估集

这是人工编写的中英文模拟个人记忆，不含真实个人信息。数据用于展示同一算法工厂
从“技术笔记检索”迁移到“有监督记忆分类”的闭环，不代表真实用户分布或生产准确率。

| 标签 | 主要意图 | 相近负例的判定规则 |
|---|---|---|
| engineering | 技术知识、原理、调试经验 | 提及项目的技术解释仍是技术知识 |
| project | 项目状态、范围、团队决策和分工 | 团队采用某界面属于项目事实，个人喜欢某界面属于偏好 |
| preference | 个人偏好和习惯 | 喜欢上午开会属于偏好，不等于明确待办 |
| reminder | 未来需要完成的动作、提醒和待办 | 整理技术笔记或提交项目报告的待办仍是提醒 |

`train.json` 有 64 条，每类 16 条；`validation.json` 和 `test.json` 各 24 条，每类 6 条。
每个 split 中英文各半。验证与测试分别有 8 条 direct、8 条 paraphrase、8 条 hard_negative；
字段为 `id/text/label/category/annotation`。

三份数据一次编写并固定，不根据测试结果修改测试样本。工厂运行前检查全部 split：
ID 全局唯一，文本经 Unicode NFKC、大小写和空白归一后全局不重复，验证和测试均覆盖所有训练类别。
同一类别共享领域词汇是预期现象，当前去重检查不保证语义层面完全独立。

算法只获得 `training_examples=[{"text":...,"label":...}]` 与待分类 `texts`，
不接收验证或测试标签。特征词表、IDF 和分类器必须仅在训练数据上拟合。
验证集用于候选比较和有限修复；选中代码和训练集冻结后仅评估一次最终测试集，测试不通过时不继续修复。

默认门槛：Accuracy ≥ 0.75、Macro-F1 ≥ 0.70、classification_p95_ms ≤ 2000。
Macro-F1 为真实/预测标签并集上各类 F1 的算术平均，零分母计 0；完整验证和测试各自覆盖四类。
P95 是同一整批文本调用三次的时长分位数，包含每次训练和预测，不包含解释器导入，不能解释为单条纯推理延迟。
同时检查返回标签有效性、等长及顺序、输入不变性、空输入/空训练、确定性、跨进程复现和空白文本多数类回退。

样本量小且类别边界经过人工设计，仍需真实授权数据、独立标注和更大规模评估后才能判断实际效果。
