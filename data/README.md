# 演示数据说明

本目录为人工编写的模拟数据，无真实个人信息。由 `scripts/create_demo_data.py` 生成：

- 24 条软件研发技术记忆：故障处理、技术方案、项目经验。
- 12 条验证查询：供候选选择、错误诊断与有限修复。
- 10 条最终测试查询：只在候选冻结后对选定版本评估，不反馈给代码生成 Agent。

标注定义为“该记忆直接回答查询”。每条查询至少一个相关 ID；允许多个相关结果。
检索无需训练分类模型：TF-IDF/BM25 只在记忆语料上构建统计量。
最终测试查询通常涉及验证查询没有覆盖的记忆主题，但这不是严格的领域外评估。
数据规模小且词面重合较高，只能证明流程可执行，不能证明真实个人记忆场景效果。
正式评估需增加自然改写、同义词、无答案查询、近似负例、长文档与不同来源。
