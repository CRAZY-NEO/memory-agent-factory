# 中文技术记忆检索：Jaccard

能力标识：char_jaccard。算法：jaccard。任务：memory_retrieval。
输入 query、memories、top_k；输出有序的 memory id 和 score。

中文使用单字及相邻双字，英文技术标识使用小写单词，将分词结果去重为集合。查询集合 Q 与文档集合 D 的 Jaccard 相似度为 len(Q & D) / len(Q | D)，并集为空时返回零。词频不参与评分，不需要训练或 IDF。只返回正分结果，分数降序，同分按 ID 排序。空查询、空语料和非正 top_k 返回空列表。标点查询无词项时返回空列表。

适用：小规模中文与英文混合技术笔记、需要轻量且可解释的词集合重合检索。
指标：Recall@k、MRR@k、Precision@k、P95 查询耗时；依赖：Python 标准库。
局限：不考虑词频与逆文档频率，长文档的并集会稀释得分；无法解决缺少词面重合的语义改写。
来源为本项目编写的演示算法说明和可复现基线实现。
