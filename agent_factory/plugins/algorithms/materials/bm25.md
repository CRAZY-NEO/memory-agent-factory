# 中文技术记忆检索：BM25

能力标识：char_bm25。算法：bm25。任务：memory_retrieval。
输入 query、memories、top_k；输出有序的 memory id 和 score。

BM25 结合词频、逆文档频率与文档长度归一化进行检索。中文使用单字和相邻双字，英文技术标识按小写单词分割。使用非负 IDF 公式 log(1 + (N - df + 0.5)/(df + 0.5))，k1=1.5、b=0.75。相同分数按 ID 排序。空查询、空语料和非正 top_k 返回空列表。

适用：不同长度的技术笔记、包含明确组件名或故障词的查询。
指标：Recall@k、MRR@k、P95 查询耗时；依赖：Python 标准库。
局限：词面匹配对纯语义改写有限；分词策略影响排序。
来源为本项目编写的演示算法说明，研究背景：
https://www.staff.city.ac.uk/~sbrp622/papers/foundations_bm25_review.pdf
